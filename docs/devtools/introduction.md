# Piant Devtools 简介

`@piant/devtools` 是 Piant 的独立、可选调试包，基于 `@tanstack/devtools-ui` 提供页面内嵌的单层底部面板。安装并在开发环境显式调用 `attachDevtools({ enabled: true, ... })` 后才会生效。

`@piant/core` 和 `@piant/store` 不依赖调试包。仅安装包、导入包或创建业务 Store 都不会自动打开面板或记录历史；应用自行决定暴露哪些状态、动画和 Store 历史。

## 四个功能页

| 功能页          | 用途                                                                                                      |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| **Elements**    | 检查 `PRoot` 下的元素树、布局、样式与变换；从画布选择元素并定位到树和属性。                               |
| **State**       | 读取显式 `getState` 快照；预览已注册的 Store 历史，明确点击 Restore 恢复可恢复记录，点击 Clear 清空历史。 |
| **Performance** | 查看 CPU 布局耗时、更新次数、Ticker 帧间隔与有界布局时间线。                                              |
| **Animations**  | 读取显式登记的动画句柄的播放状态、时间与观测统计。                                                        |

面板支持元素搜索、树折叠、深浅主题、拖动调整高度，以及收起后保留浏览位置。元素树展示底层 `PNode`，不追踪函数组件调用关系；性能数据不代表 GPU 耗时或完整浏览器追踪。

## 安装与启用

在已有 Piant 应用中单独安装：

```bash
pnpm add -D @piant/devtools
```

调试包需要应用提供兼容的 `@piant/core ^0.2.0` 与 `pixi.js ^8.22.0`。将动态导入放在构建工具可静态替换的开发条件内，避免生产产物包含调试实现；仅设置 `enabled: false` 不会代替生产剔除。

面板是浏览器端工具。使用 SSR 的应用应在客户端初始化后动态导入，避免在服务端直接加载调试包。
