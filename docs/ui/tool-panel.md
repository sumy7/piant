# 图层工具面板

在分栏左侧搜索图层，在右侧调整缩放和输出预设。拖动中间的分隔条，可以给当前区域留出更多空间。

<LiveExample example="uiToolPanel" title="搜索图层、数值缩放、分栏与输出预设" :height="700" hide-source />

## 用到的组件

- [SearchField](/ui/search-field) 随输入筛选图层，Enter 提交搜索。
- [NumberField](/ui/number-field) 编辑缩放比例，按步长调整或提交输入值。
- [Combobox](/ui/combobox) 随输入筛选预设，选中后更新当前值。
- [SplitPane](/ui/split-pane) 调整两侧区域的宽度，也可聚焦分隔条后用方向键移动。

另见[设置面板](/ui/gallery)和[文档编辑](/ui/workflow)。
