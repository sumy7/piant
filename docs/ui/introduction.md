# Piant UI 组件目录

`@piant/ui` 为 Canvas 界面提供按钮、表单、布局、弹窗和数据浏览组件，适合构建设置页、编辑器和工具面板。按用途选择组件，即可在对应页面操作预览并查看 TSX 用法。
